# Reporting a security problem

If you've found a security problem in InternetDJ or anything documented here, please report it privately rather than in a public issue.

Use **[Report a vulnerability](../../security/advisories/new)** on this repository's Security tab. Only the maintainers can see what you send.

Please include what you found, how to reproduce it, and what someone could do with it. We'll reply as soon as we can and let you know when it's fixed.

Please don't access other members' data, disrupt the site, or run automated scans against it while looking.
